# Jane Doe - Photographer Portfolio

## Overview
The project presents Jane Doe’s photography work through a clean, image-focused interface designed to showcase individual projects, galleries, and selected work. It includes dynamic project pages, organized galleries, and content management features that make it easy to maintain and update the portfolio.
